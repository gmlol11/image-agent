# Image Agent ✨

Ультра-минималистичный локальный интерфейс для генерации изображений на Apple Silicon (MacBook Air M5, 16 GB Unified Memory).

## Философия

Пользователь описывает желаемую сцену обычным человеческим языком. Система самостоятельно определяет все технические параметры (соотношение сторон, разрешение, LoRA-адаптеры, отрицательные промпты, подавление артефактов и композиционные директивы).

Пользователь не должен сталкиваться с терминами вроде *CFG, Sampler, LoRA, Checkpoint, Seed, Negative prompt, VAE, Steps*.

---

## Архитектура

- **Planning Layer:** Bonsai 2 27B (через локальный OpenAI API) или автоматический эвристический fallback (*Simple Mode*), если LLM временно выключен.
- **Inference Engine:** Draw Things 26+ на порту `7860` с моделью Z-Image Turbo 1.0 (квантование 6-bit) и Metal/MPSGraph ускорением.
- **Backend:** FastAPI (Python 3.11+, async, sequential execution для оптимизации 16 GB RAM).
- **Frontend:** Легковесный SPA (HTML5, modern CSS, ванильный JS, Apple Human Interface Guidelines).
- **Privacy:** 100% localhost only, zero cloud dependencies.

## Быстрый старт

### Вариант 1: Без консоли (macOS App)
На Рабочем столе (Desktop) и в папке проекта созданы ярлыки:
- **`▶️ Запустить Image Agent.app`** — в один клик в фоновом режиме запускает необходимые сервисы (Draw Things, Bonsai 2 27B и бэкенд), ждёт готовности, присылает системное уведомление macOS и автоматически открывает интерфейс в браузере.
- **`⏹️ Остановить Image Agent.app`** — останавливает серверы и освобождает ~6–8 ГБ объединённой памяти (Unified Memory).

### Вариант 2: Через терминал
```bash
cd image-agent
./run.sh
```

Скрипт автоматически:
1. Проверит окружение `.venv` и зависимости.
2. Проверит доступность Draw Things API и Bonsai 2.
3. Запустит веб-сервер на `http://127.0.0.1:8000`.
4. Откроет браузер.

## Настройка пресетов

Все рабочие параметры, веса LoRA и отрицательные промпты вынесены в:
```text
config/presets.json
```
Значения можно изменять без правок Python-кода.

## Основные возможности

1. **Единое поле ввода:** «Что хочешь получить?».
2. **Автоматический выбор геометрии:**
   - Полноростовые фигуры людей — строго вертикальный формат (`768×1152`), решающий проблему обрезки головы/ног.
   - Предметная реклама — квадрат (`1024×1024`) с автоматическим подавлением типографики и случайных логотипов.
   - Пейзажи и кинематографичные сцены — горизонтальный формат (`1152×768`).
3. **Автоматическая маршрутизация LoRA:**
   - Фото людей и кожи — автоматическое подключение `Realism LoRA (0.60)`.
   - Взрослый и художественный арт — автоматическое подключение `Unrestricted LoRA (0.85)` и контроль возраста персонажей `25+`.
4. **Прогрессивный рендеринг:** готовые изображения появляются в сетке сразу по мере готовности, не ожидая завершения всей серии из 4 штук.
5. **Действия с изображениями:** Скачать, Сделать ещё, Улучшить (Final), Похожее (new seed).
6. **Advanced Mode:** полностью скрытый по умолчанию блок для тонкой ручной настройки (перекрывает авторешения).
